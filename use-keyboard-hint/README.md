# use-keyboard-hint

An [Astryx](https://astryx.atmeta.com/components/useKeyboardHint)-based implementation of the `useKeyboardHint` hook.

## Development

```bash
git clone --depth 1 --branch v0.7.0 https://github.com/facebook/astryx
```

Install [fnm](https://github.com/Schniz/fnm) (if necessary).

```bash
fnm install && fnm use && node --version && npm --version
```

```bash
npm install
```

```bash
npm run prepare
```

```bash
npm run dev
```

```bash
npm run format
```

```bash
npm run lint
```

## Deployment

```bash
npm run build
```
