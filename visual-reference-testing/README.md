# visual-reference-testing

## Development

Install [fnm](https://github.com/Schniz/fnm) (if necessary).

```bash
fnm install && fnm use && node --version && npm --version
```

```bash
npm install
```

```bash
npm run prepare
```

```bash
npm run dev
```

```bash
npm run format
```

```bash
npm run lint
```

```bash
npm run test:reference
```

```bash
npm run test
```
